# Used Car Price ML Service

Servicio reproducible de aprendizaje automático para estimar el precio anunciado de vehículos usados y proporcionar un intervalo de predicción orientativo.

## Estado

Proyecto en desarrollo. Actualmente se encuentra en la etapa de preparación y análisis exploratorio de datos.

## Entorno

El proyecto utiliza Python 3.12 y `uv` para gestionar dependencias.

```bash
uv sync
```

Los datos originales no se incluyen en el repositorio. Su procedencia e instrucciones de descarga se documentan en `DATA_SOURCE.md`.
